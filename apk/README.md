# Release APKs

## Where to get the app

**Download from the
[Releases page](https://github.com/JuggyBob/DiscountHunterAndroid/releases/latest) → Assets**, not
from this folder.

Release assets are served to a phone as real downloads. A binary committed to a repository is not:
GitHub fetches it through the repository's raw file path, so a phone browser tends to either refuse
it or save it under the wrong name and extension. That is the whole reason this file exists — to
point somewhere that works.

Every release carries:

| Asset | What it is |
|-------|------------|
| `discount-hunter-<version>.apk` | The optimised release build |
| Source code (zip) | Generated by GitHub from the tagged commit |
| Source code (tar.gz) | Same, as a tarball |

The APK is built by the `Release` workflow in CI, not uploaded by hand, so the file you download is
the one the tests and lint ran against.

The copy in this folder is a local build artefact kept for convenience. It is not what the README
links to, and it will drift from the releases.

## Installing

**The APKs are unsigned**, so Android will refuse them the first time. That is expected:

1. Tap the downloaded `.apk` in your file manager.
2. Android will say the file is from an unknown source. Tap **Settings** → allow your file manager
   to install apps.
3. Go back and tap the APK again.

To remove that permission afterwards: **Settings → Apps → (your file manager) → Permissions →
Install unknown apps → Deny**.

Requires **Android 7.0 (API 24)** or newer. Portrait orientation only.

## Verifying what you downloaded

The build is reproducible from the tagged source, so you can check that the APK matches the code:

```bash
git checkout v1.0.0
./gradlew assembleRelease
```

The resulting APK will not be byte-identical to the one here — Android build tools embed timestamps
and a build id — but its `versionName` and `versionCode` will match, and `aapt dump badging` on both
should agree.

## Building your own

Better if you want to change something, or you want a signed build for your own device:

```bash
git clone https://github.com/JuggyBob/DiscountHunterAndroid.git
cd DiscountHunterAndroid
echo "sdk.dir=/path/to/Android/sdk" > local.properties
./gradlew assembleDebug     # debug build
./gradlew assembleRelease   # release build
```

For a signed release, see the commented signing steps in [`.github/workflows/release.yml`](../.github/workflows/release.yml).
